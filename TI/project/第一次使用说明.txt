========================================================================
 F28P55x 300W 开环工程 —— 第一次使用说明
========================================================================

【目录结构】
E:\TI\
  ccs\           CCS 21.0.1（TI官方IDE，等于Keil）
  c2000ware\     C2000Ware SDK（TI官方器件库/驱动库）
  project\       ← 工程就在这个文件夹
    src_openloop\           源文件+工程描述文件（导入用）
      openloop_300W.projectspec   TI官方工程描述文件
      app_openloop.c              主程序（改工况改这里）
      lnk.cmd                     链接脚本
    打开工程.bat                  双击打开CCS

------------------------------------------------------------------------
【第一次：导入工程（只做一次，约30秒）】
------------------------------------------------------------------------
1. 双击  E:\TI\project\打开工程.bat
   等CCS完全打开（第一次可能要2~5分钟，窗口不转圈了才算好）

2. 菜单：File → Import... → 选 CCS Projects → 点 Next

3. 在路径框里选到：
   E:\TI\project\src_openloop
   下面会显示发现的项目 openloop_300W

4. ★★ 关键一步 ★★
   点下面那个灰条 "Import destination..."
   选  E:\TI\project
   （不选这个，右下角的 Finish 就是灰的、点不了！）

5. 这时 Finish 变亮 → 点 Finish

导入完成后，左边资源管理器里就有了 openloop_300W 工程。

------------------------------------------------------------------------
【以后：日常开发（跟Keil一模一样）】
------------------------------------------------------------------------
双击 打开工程.bat  →  CCS打开，工程还在（不用再导入）

改工况：双击工程里的 app_openloop.c，改开头这5个数：
        #define OL_FS_KHZ   275.0f    开关频率kHz
        #define OL_D1       0.3603f   桥A占空比(0~1)
        #define OL_D2       0.6961f   桥B占空比(0~1)
        #define OL_PHI_NS   747.0f    移相ns
        #define OL_DT_NS    100.0f    死区ns
        Ctrl+S 保存

编译：  Ctrl+B     （或点锤子图标）
烧录：  点绿色虫子图标 Debug（或按F11）
        烧完点 Run → Resume（或F8）让程序跑

------------------------------------------------------------------------
【串口调参（不用编译，最快）】
------------------------------------------------------------------------
任意串口助手 → COM5 @115200
发命令：
  F 250     频率250kHz
  A 75.59   D1=75.59%
  B 47.00   D2=47%
  P 727     移相727ns
  T 100     死区100ns
  X         翻转极性
  R         重新软启动
  S         查询当前参数
板子每改一条立刻回报 [OL] OK ...

------------------------------------------------------------------------
【接线（到300W功率板）】
------------------------------------------------------------------------
LaunchPad GPIO0 → 桥A上管驱动     (EPWM1A)
LaunchPad GPIO1 → 桥A下管驱动     (EPWM1B, 自动互补+死区)
LaunchPad GPIO2 → 桥B上管驱动     (EPWM2A, 移相)
LaunchPad GPIO3 → 桥B下管驱动     (EPWM2B, 自动互补+死区)
GND  ←→ 功率板GND  （必须共地！）

------------------------------------------------------------------------
【注意】
------------------------------------------------------------------------
- 时钟SYSCLK=150MHz（不是200MHz），改频率公式 fs=150MHz/(2*TBPRD)
- 默认配方是 48V→24V/4A：275kHz / D1=36.03% / D2=69.61% / φ=747ns
- 若驱动是反相的（波形不对），串口发 X 翻转一次

========================================================================
【AI 功能：片上 DBN 策略网络】
========================================================================
固件里已集成在 F28P55x 上运行的 DBN（4->32->32->4，1348参数，约5.4KB float32）。

串口发一条命令就完成"AI算配方+应用+软启动"：

    G <Vin_cV> <Vref_cV> <Io_dA>

  例： G 3600 2400 10      = 36V输入 → 24V输出 / 1.0A
       G 2400 3600 50      = 24V → 36V / 5A（升压）
       G 4800 2400 80      = 48V → 24V / 8A

板子会回两行：
    [AI] VIN=36.00 VREF=24.00 IO=1.00 -> FS=278.0kHz D2=49.21% PHI=228ns
    [AI] D1_TBL=37.97% D1_CORR=38.45% dELTA=2.78% B=0.04

其中：
  D1_TBL  = 网络直接输出的表值（仅参考）
  D1_CORR = 死区伏秒修正后的D1（这个才是实际写进EPWM的）
  dELTA   = 死区占空比当量 δ = td·fs
  B       = 桥B死区补回系数（移相越大越接近1.33）

DBN训练数据 = LUT4V（3.6µH / GaN LMG2100R044 / 30~300kHz / 18070点）
验收结果：对比LUT最优解，效率损失平均 -0.03pp，98%工况点 < 0.5pp

【已验证】固件输出与训练结果逐位一致；EPWM寄存器(POLSEL/TBPRD/CMPA/TBPHS)全部正确
【当前限制】Vin/Vref/Io 是命令给定（开环前馈），未接ADC闭环
            —— 若要闭环，需要确认300W板的电压/电流采样接到LaunchPad哪几个引脚
